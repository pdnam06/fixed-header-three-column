# Fixed Header Three Column Layout

Bài thực hành xây dựng trang web gồm:

- Header cố định bằng `position: fixed` và `z-index`.
- Sidebar trái.
- Nội dung chính co giãn với `flex-grow`.
- Sidebar phải.
- Bố cục Flexbox và giao diện responsive.

Mở `index.html` bằng trình duyệt và cuộn trang để kiểm tra header cố định.
